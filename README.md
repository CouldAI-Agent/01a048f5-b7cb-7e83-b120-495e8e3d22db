# ವಿಮೋಚನಕಾಂಡ 18: ಅರ್ಥ (Exodus 18 Meaning)

ವಿಮೋಚನಕಾಂಡ 18ನೇ ಅಧ್ಯಾಯದ ಸಾರಾಂಶ ಮತ್ತು ಅರ್ಥವನ್ನು ವಿವರಿಸುವ ಫ್ಲಟರ್ ಅಪ್ಲಿಕೇಶನ್. ಇದು ಬೈಬಲಿನ ಪ್ರಮುಖ ಘಟನೆಗಳಾದ ಇತ್ರೋವನ ಭೇಟಿ, ದೇವರ ಸ್ತುತಿ, ಮತ್ತು ನಾಯಕತ್ವದ ಜವಾಬ್ದಾರಿ ಹಂಚಿಕೆಯನ್ನು (Delegation) ಕನ್ನಡದಲ್ಲಿ ಸುಂದರವಾಗಿ ವಿವರಿಸುತ್ತದೆ.

## ಪ್ರಮುಖ ಲಕ್ಷಣಗಳು (Features)
- ಸಂಪೂರ್ಣವಾಗಿ ಕನ್ನಡ ಭಾಷೆಯಲ್ಲಿದೆ.
- ವಿಮೋಚನಕಾಂಡ 18ನೇ ಅಧ್ಯಾಯದ ಪ್ರಮುಖ ಘಟನೆಗಳ ಸಾರಾಂಶ.
- ಸುಂದರವಾದ ಮತ್ತು ಓದಲು ಸುಲಭವಾದ ಕಾರ್ಡ್ ವಿನ್ಯಾಸ (Material Design 3).
- ಎಲ್ಲಾ ಸಾಧನಗಳಲ್ಲಿ (Mobile, Web, Desktop) ಹೊಂದಿಕೊಳ್ಳುವ ವಿನ್ಯಾಸ (Responsive).

## ತಂತ್ರಜ್ಞಾನ (Tech Stack)
- Flutter
- Dart
- Material Design 3

## ಹೇಗೆ ನಡೆಸುವುದು (How to Run)
1. Flutter SDK ಇನ್‌ಸ್ಟಾಲ್ ಆಗಿದೆಯೇ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ.
2. ಪ್ರಾಜೆಕ್ಟ್ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಈ ಕಮಾಂಡ್ ಚಲಾಯಿಸಿ:
   ```bash
   flutter pub get
   flutter run
   ```
